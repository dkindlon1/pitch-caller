### 0.5 Current suite
Note on the Python golden check. `python3 golden/golden_v09.py check` requires exact float equality. On this Mac it
reports `FAIL: 26547 differences`, largest 1.14e-13, under both Python 3.14.6 and 3.13.2: the differences are last-bit
rounding (e.g. `golden 1.950780451244071 now 1.9507804512440712`). The same check in a Linux container
(`docker run python:3.13-slim`, glibc 2.41, Python 3.13.18) gives `500 cases, largest difference 0.00e+00 / PASS: v0.9
reproduced exactly`. So the golden was made on Linux and macOS's libm rounds exp/log differently in the last bit. CI
(ubuntu, Python 3.13) doesn't run this check; it runs only the JS golden, which passes here. For the rest of this run,
exact-equality Python golden checks are run in that Linux container. The venv was rebuilt on Python 3.13 to match CI.
