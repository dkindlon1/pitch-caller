# Test data

`Track_Combo.csv` is from Nathan David Pifer, "Optical Tracking Data from College Baseball Scrimmages", Mendeley Data,
V1, 2024, doi:10.17632/xfnz6mkdzm.1 (https://data.mendeley.com/datasets/xfnz6mkdzm/1). It is licensed CC BY 4.0
(https://creativecommons.org/licenses/by/4.0/) and is included here unchanged (SHA-256
`7b7b8974107be6181dcf1880d609034ef9f7556f9fb13aec021a52d37cd0c190`). Its author doesn't endorse PitchIQ.

It is 3,344 TrackMan V3 pitches by 32 college pitchers, anonymized to IDs. `web/lib/trackcombo.test.ts` runs the
upload pipeline on it (spec check D10).
